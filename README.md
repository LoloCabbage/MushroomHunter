# 这个仓库整理一些采蘑菇常用的数据和网站，帮助大家科学采蘑菇。🍄

作为一个蘑菇爱好者，最近使用ai等资源找到了很多蘑菇相关的信息。希望通过这个仓库分享这些信息，让采蘑菇这一活动更加安全、环保、科学。如果错误之处，欢迎大家指出和讨论（Feel free to submit issues:)

这个仓库包括的主要资源有：
- 1.具体国家的采蘑菇攻略，{国家名称}.md,包含了采蘑菇的法律法规、物种图鉴、气象预报等实用信息。
- 2.记录蘑菇物种的模版。
- 3.未完待续

**蘑菇鉴定是很复杂很专业的行为，本仓库不作任何野生菌鉴定参考。主要目的整合资源，帮助大家在本地找到合适的真菌相关信息。**
